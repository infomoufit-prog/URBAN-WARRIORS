# KOMBAX 20.101 R47 · Social Visibility + Media Flow

R47 corrige el contrato de R46: no existe «Ocultar para mí» en el flujo activo. La preferencia personal es «Me interesa / No me interesa / Sin preferencia» y afecta relevancia, no visibilidad. La visibilidad es una decisión independiente del propietario y puede editarse también después de publicar desde `··· > Visibilidad`.

Multimedia móvil: vertical 4:5, cuadrada 1:1, horizontal 16:9; al tocar/expandir se usa visor inmersivo a pantalla completa con `contain` para conservar el original completo.

Estado: **PRE-QA / QA candidate**. Suite/build/paridad y backend R47 verificados; QA móvil autenticado real, advisors de cierre y firma Android local continúan como gates separados. No es una declaración production-ready.
