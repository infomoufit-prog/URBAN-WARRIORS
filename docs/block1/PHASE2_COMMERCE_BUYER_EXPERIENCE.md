# KOMBAX Block 1 · Phase 2 buyer experience
Build 20135.

Implemented:
- Display products keep non-Commerce interest/contact behavior.
- Commerce products expose Buy now and Add to cart.
- Quantity control and variant/option selector when catalog data already contains variants.
- Persistent buyer cart with edit/remove/clear and totals from authoritative product prices.
- Single-seller isolation: one cart cannot mix Showcase providers/Connected Accounts.
- Seller/verification, stock and fulfilment remain visible in product detail.
- Adult and marketplace-terms gate before cart checkout.
- Responsive mobile cart UI and 8-locale Commerce copy.

Phase 2 defines the client cart checkout contract; Phase 3 closes that contract server-side without removing the legacy single-product path.
