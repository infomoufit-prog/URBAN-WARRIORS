# KOMBAX R64 - Perfiles y relaciones

## Perfiles raíz
- Espectador
- Competidor
- Profesional
- Media Creator / Creador
- Club
- Federación
- Marca

## Profesional
Entrenador y Organizador/Promotor son subcategorías de Profesional. Reutilizar IDs existentes (`entrenador`, `promotor_organizador`) y no crear raíces duplicadas.

## Relaciones, no planes
Alumno, Miembro y Tutor son relaciones con Club. Una misma cuenta puede conservar otra identidad personal y además pertenecer a uno o varios clubes.

## Espectador
- Social: ver, Like, comentar; no publicar.
- Showcase: ver, pedir información, comprar si >=18.
- Events: ver, informarse, comprar entradas si >=18.
