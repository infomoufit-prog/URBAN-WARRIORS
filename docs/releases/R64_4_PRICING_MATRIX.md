## Reglas de Destacar

Destacar es un único servicio para Event o producto Showcase. Incluye prioridad dentro de su módulo y amplificación automática en KOMBAX Social. Mantiene:
- máximo 2 Events promocionados por usuario/día;
- nunca dos promociones consecutivas;
- mismo Event máximo una vez por usuario cada 72 horas.
