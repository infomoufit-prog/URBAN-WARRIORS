# R60 — diseño interno de Migraciones, guía e historial

## Regla de producto
La transferencia de datos es una fricción organizativa. La guía y KOMBAX Migrations se exponen únicamente en **Club** y **Federación**. No forman parte de la experiencia de Miembro, Competidor, Marca, Profesional, Media/Creador o Espectador.

## Regla de identidad
- Cuenta KOMBAX = identidad global.
- `socios` / federados = registros administrativos.
- Membresía = relación privada con una organización.
- Un registro importado no crea Auth artificial.
- 16+ nuevo: email desde preinscripción y activación vinculada a la ficha.
- Histórico sin email: administrativamente válido, KOMBAX pendiente.
- Menor de 16: acceso mediante tutor; el tutor nunca sustituye la identidad administrativa del menor.

## Regla de migración
Excel/CSV, PDF e imágenes se procesan de forma conservadora:
**analizar → preguntar → normalizar → vista previa → confirmar**.
Nunca se debe importar automáticamente desde una conversación.

## Regla de borrado
El usuario puede borrar contenido, no consumo. El sistema elimina contenido recuperable y Storage, conserva únicamente metering/auditoría mínima y mantiene los límites del plan.
