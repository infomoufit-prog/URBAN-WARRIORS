# KOMBAX — respuesta mínima a incidentes

Severidad crítica: acceso cruzado entre clubes, compromiso Owner/service_role, exposición documental/financiera, alteración masiva o pérdida de integridad.

Acciones: 1) contener (pausar pilot/recurring, cerrar sesiones privilegiadas, revocar/rotar secreto afectado); 2) preservar logs/auditoría; 3) identificar entidades/personas afectadas; 4) restaurar desde estado conocido si procede; 5) corregir y validar; 6) documentar cronología/causa/medidas; 7) gestionar comunicaciones y obligaciones legales aplicables.

Nunca borrar la evidencia de auditoría para “limpiar” un incidente.
