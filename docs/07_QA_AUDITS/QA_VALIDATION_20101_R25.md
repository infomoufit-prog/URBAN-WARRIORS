# KOMBAX 20.101 R25 · PILOT STABILIZATION — QA VALIDATION

## Scope
R25 is a frontend/lifecycle stabilization revision built from R23 after a no-code R23 audit. It deliberately does **not** introduce Supabase schema/data changes, new RPCs, or new product features.

## Root causes addressed
- `Me interesa`: async listener used `event.currentTarget` after `await`, producing `Cannot set properties of null (setting 'textContent')`.
- Equivalent stale-event-target patterns found and corrected in Events external-video handling and Showcase save handling.
- Events album hydration inserted/replaced media before decode, could blank/retry stages, and forced all remaining cards to hydrate after 1.4 s.
- Events detail modal lacked a lifecycle signal for observer cleanup.
- Events detail cache had TTL but no cardinality cap.
- Android/WebView Events detail used multiple compositor-expensive effects during continuous scroll.

## Implemented stabilization
- Stable element reference captured before async suspension; duplicate submission guard; UI update only while node remains connected.
- Modal emits `kx:modal-before-close` before removal so observers/tasks can clean up.
- Media is loaded/decoded off-DOM before replacing the stable placeholder.
- Hydration is idempotent/inflight guarded and proximity-based; no global 1.4 s hydrate-all burst.
- Observer disconnects on detail close.
- Event detail cache capped at 24 entries.
- Mobile Events detail removes/reduces selected backdrop blur, animation, filters and transition costs while preserving layout and Fight Card hierarchy.
- Cache revision bumped to R25.
