# KOMBAX Consultoría · arquitectura de contenido previa

## Propósito
Convertir dudas generales surgidas en KOMBAX Guías en una solicitud estructurada de revisión específica, sin hacer pasar una respuesta automática por asesoramiento profesional definitivo.

## Escalado desde Guías
Cada guía incluye “Cuándo pasar a KOMBAX Consultoría”. El CTA no debe afirmar que KOMBAX puede resolver cualquier materia internamente. Debe clasificar el caso y, cuando corresponda, indicar que la resolución final exige profesional jurídico, fiscal, laboral, técnico, sanitario o federativo competente.

## Formulario futuro
- Tipo de entidad
- Comunidad autónoma / municipio
- Modalidad/disciplina
- Tipo de consulta
- Fecha objetivo
- Resumen del caso
- Documentos adjuntos
- Menores implicados (sí/no)
- Deportistas extranjeros (sí/no)
- Venta de entradas (sí/no)
- Recinto definido (sí/no)
- Federación/organización deportiva implicada

## Estados futuros
Solicitada → Clasificada → Información pendiente → Presupuestada → Aceptada → Pagada → En revisión → Entregada → Cerrada

## Pricing
La arquitectura soportará tarifa fija, “desde” o presupuesto. **No hay importes aprobados en este bloque**, por lo que cualquier cantidad visible se mantendrá fuera del producto hasta validación expresa.
