# KOMBAX · Bloque previo de diseño y contenidos
## Plan de ejecución validado

**Base única:** R81 build 20134 · Fase 0 auditada.
**Objetivo de este bloque:** preparar identidad visual y contenido documental verificable para KOMBAX Guías, KOMBAX Consultoría y KOMBAX Formación sin activar todavía módulos funcionales en producción.

### Regla de seguridad documental
1. Prioridad de fuentes: BOE/CSD, administración autonómica, AEPD/AEAT y federaciones/organismos oficiales cuando una materia dependa de ellas.
2. Ningún requisito jurídico, federativo, fiscal o administrativo se presentará como universal si depende de disciplina, federación, municipio, recinto o comunidad autónoma.
3. Cuando falte certeza: se indicará qué dato debe verificarse y ante qué organismo; no se completará por inferencia.
4. Cada guía tendrá ámbito, fecha de revisión, fuentes y un bloque “Cuándo solicitar KOMBAX Consultoría”.
5. Los ejemplos serán ilustrativos, nunca sustitutos de la norma ni simulaciones de autorización oficial.

### Etapas
**A. Auditoría visual.** Revisar heroes, portadas, paletas, composición, densidad, responsive y uso del símbolo KOMBAX. Definir brief de tres nuevas familias visuales.

**B. Investigación.** Crear matriz de fuentes por materia y separar marco estatal de capa autonómica. La primera capa autonómica completa será Cataluña; para el resto de CCAA se dejará arquitectura preparada y se señalará la necesidad de verificación territorial antes de publicar requisitos específicos.

**C. Contenido.** Elaborar 15 guías iniciales estructuradas. Cada una: objetivo, ámbito, requisitos verificables, pasos, checklist, documentación, riesgos/errores, ejemplos, fuentes, actualización y derivación a Consultoría.

**D. Publicación documental.** Generar un PDF profesional individual por guía y un dossier maestro navegable. Los PDF se incorporarán como artefactos/documentación, no como módulo funcional activo.

**E. Assets.** Generar y revisar assets para KOMBAX Guías, KOMBAX Consultoría y KOMBAX Formación, coherentes con la estética dark-premium existente y claramente diferenciados entre sí.

**F. QA y empaquetado.** Validación factual documental, revisión visual de PDF, comprobación de archivos, manifest/checksum y ZIP acumulativo. No iniciar las fases funcionales 1–5.

### Fuera de alcance de este bloque
- No crear todavía rutas/UI productivas de Guías/Consultoría/Formación.
- No modificar planes comerciales definitivos ni fijar precios de Consultoría sin validación del usuario.
- No activar KOMBAX Formación para usuarios.
- No ejecutar las fases funcionales 1–5 del Plan Maestro.
