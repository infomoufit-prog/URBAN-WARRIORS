# KOMBAX Formación · arquitectura privada previa
**Fecha:** 21/09/2026  
**Estado:** diseño/contenido preparatorio; módulo NO visible ni activado

## Propósito
KOMBAX Formación será una capa separada de KOMBAX Guías y KOMBAX Consultoría. Está pensada inicialmente para el piloto con una federación/colegio profesional que ofrece formación, prácticas, licencias formativas y recursos ISO, e incluirá un módulo práctico sobre el uso de KOMBAX como plataforma de gestión.

## Regla de visibilidad
Por defecto la capa no existe en la navegación del usuario. La futura implementación requerirá un entitlement explícito, conceptualmente `training_enabled = true`, asociado a una identidad autorizada.

## Perfiles previstos
- Alumno/a.
- Formador/a.
- Coordinación académica.
- Federación/colegio profesional.
- Administración técnica KOMBAX.

## Áreas preparadas
- Cursos.
- Módulos.
- Prácticas.
- Recursos y documentación aportada por la entidad, incluidos recursos ISO cuando corresponda.
- Licencias formativas.
- Evaluaciones.
- Seguimiento/progreso.
- Certificados o acreditaciones según el marco real de la entidad emisora.
- Módulo práctico: gestión digital de clubes y eventos con KOMBAX.

## Límites de este bloque
No se inventan cursos, acreditaciones oficiales, equivalencias, horas, precios, licencias, estándares ISO concretos ni capacidad certificadora de la entidad colaboradora. Esos datos deberán incorporarse desde documentación real del acuerdo/piloto.
