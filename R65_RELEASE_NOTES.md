# KOMBAX R65 · Release Notes

**Versión:** R65 · build 20116  
**Base:** R64.4 · build 20115

### Entregado

- Showcase Finance Center.
- Events Finance Center.
- Reembolsos Stripe desde KOMBAX, totales y parciales.
- Refunds idempotentes y compatibles con direct charges/application fees.
- Reposición de stock separada y auditable.
- Batches reanudables para reembolsos de eventos.
- Comunicaciones transaccionales integradas con outbox/dispatcher.
- BI Enterprise para Showcase y Events.
- Historial operativo QR/check-in para organizadores.
- Ledgers R65 privados con RLS y RPC internos restringidos.
- Build 20116 sincronizado en web/dist/Android assets.

### Conservado de R64.4

- Precios y catálogo comercial R64.4.
- Club Basic: Showcase 15 productos sin Commerce incluido; Commerce temporal 12 €/30 días.
- Premium: Showcase 25 productos y Commerce incluido.
- Destacar: 3 €/7 días, 5 €/15 días, 8 €/30 días.
- Ticketing por capacidad y fees de plataforma según plan.
- Gate de compra 18+.
- Stripe Connect con direct charges.
- Ticket QR, Wallet, scanner y roles de acceso.

### Fuera de alcance intencional

KOMBAX SaaS Billing (suscripciones y cobro automático de add-ons propios de KOMBAX) queda para la siguiente fase.
