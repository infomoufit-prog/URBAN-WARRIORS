# Decisión R32 · Funciones Pro posteriores

R32 cierra el núcleo básico. No se crean tipos como “Entrenador Pro”; las ventajas futuras se añadirán por plan/entitlements.

## Competidor Pro — posterior
Según el Plan Maestro, quedan fuera de esta activación básica:
- media kit avanzado;
- sponsors;
- analítica ampliada;
- oportunidades premium;
- dossier profesional;
- herramientas económicas específicas;
- otras ventajas comerciales.

## Marca Pro — posterior
- analítica;
- campañas;
- oportunidades;
- mayor capacidad Showcase;
- herramientas comerciales;
- patrocinios.

## Profesional Pro — decisión estructural
- Tipo: Profesional.
- Subtipo: Entrenador / Manager / Médico / Árbitro / Promotor.
- Plan: Base / Pro.
- La pérdida de un futuro plan Pro no cambia el tipo/subtipo; solo retira capabilities Pro.

## No decidido en R32
El Plan Maestro deja explícitamente fuera las funciones Pro finales y los precios definitivos. No se fijan aquí precios, límites comerciales ni nuevos entitlements de pago.
