# R71 Release Notes

- KOMBAX Events pasa a acordeón de barra lateral.
- KOMBAX Showcase pasa a acordeón de barra lateral.
- `Explorar Eventos` y `Explorar Showcase` conservan las rutas públicas.
- `Mis Eventos` y `Mi Showcase` se muestran dentro de su acordeón solo cuando el usuario dispone del permiso correspondiente.
- El acordeón activo se abre automáticamente y recuerda su estado.
- Estética coherente con Mi Club, con acento cian para Events y dorado para Showcase.
- Sin cambios en precios, Commerce, Ticketing, Stripe, permisos backend o contratos.
