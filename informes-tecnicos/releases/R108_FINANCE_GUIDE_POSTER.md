# R108 · Guía de Finanzas y cartel de club

## Cambios

- Guía completa de Finanzas disponible dentro de Finanzas, Finanzas Premium, Avisos de cobro y KOMBAX Guías.
- PDF de nueve páginas con cargos, automatizaciones, pagos manuales, pagos parciales, Stripe, SEPA, avisos, recibos e informes.
- Ayuda rápida desplegable y adaptada a móvil.
- Cartel de descarga para clubes sustituido por la pieza facilitada para el piloto.
- Acciones explícitas para abrir, descargar e imprimir el cartel en A4.

## Compatibilidad

- Sin cambios de base de datos ni de contratos backend.
- Conserva rutas y permisos existentes.
- El PDF se incluye dentro del paquete web y del paquete Android mediante el proceso de build acumulativo.
